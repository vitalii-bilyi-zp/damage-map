# Таблиці, що використовуються для OLAP-куба

## 1. damage_notes — Таблиця фактів (Акти пошкоджень)

Центральна таблиця куба. Кожен рядок — це один зафіксований акт пошкодження об'єкта інфраструктури.

| Колонка                 | Тип            | Опис                                                                                                          |
|-------------------------|----------------|---------------------------------------------------------------------------------------------------------------|
| id                      | bigint PK      | Унікальний ідентифікатор акту                                                                                 |
| date                    | date           | Дата фіксації пошкодження. Використовується для часових вимірів (день/тиждень/місяць) та фільтрації за період |
| object_type_id          | bigint FK      | Посилання на тип об'єкта. Через цю колонку куб групує дані за типом та категорією об'єкта                     |
| community_id            | bigint FK      | Посилання на територіальну громаду. Через цю колонку куб будує географічну ієрархію (громада > район > регіон) |
| damage_type             | enum           | Ступінь пошкодження: low (легке), medium (середнє), high (тяжке). Окремий вимір куба                         |
| restoration_cost        | decimal(15,2)  | Вартість відновлення об'єкта у гривнях. Використовується як міра SUM(restoration_cost)                        |
| area                    | decimal(12,2)  | Площа об'єкта (м²). В кубі не використовується, але є в таблиці                                              |
| floors                  | int            | Кількість поверхів. В кубі не використовується                                                                |
| city, street, building_number | string   | Адреса об'єкта. В кубі не використовується                                                                    |
| repair_type_id          | bigint FK      | Тип ремонту. В кубі не використовується                                                                       |
| predicted_restoration_cost | decimal(15,2) | Прогнозована вартість (від ML-моделі). В кубі не використовується                                            |
| comment                 | text           | Коментар до акту. В кубі не використовується                                                                  |


## 2. object_categories — Категорії об'єктів

Верхній рівень класифікації пошкоджених об'єктів (наприклад: "Житлові будівлі", "Об'єкти освіти", "Інфраструктура" тощо).

| Колонка | Тип       | Опис                                                                    |
|---------|-----------|-------------------------------------------------------------------------|
| id      | bigint PK | Унікальний ідентифікатор категорії                                      |
| name    | string    | Назва категорії. Виводиться як title у вимірі object_category           |


## 3. object_types — Типи об'єктів

Конкретний тип об'єкта всередині категорії (наприклад: категорія "Житлові будівлі" -> типи "Багатоповерхівка", "Приватний будинок").

| Колонка            | Тип       | Опис                                                            |
|--------------------|-----------|-----------------------------------------------------------------|
| id                 | bigint PK | Унікальний ідентифікатор типу                                   |
| object_category_id | bigint FK | Посилання на батьківську категорію (object_categories)          |
| name               | string    | Назва типу об'єкта. Виводиться як title у вимірі object_type   |


## 4. regions — Регіони (області)

Найвищий рівень географічної ієрархії (наприклад: "Харківська", "Донецька").

| Колонка | Тип       | Опис                                                       |
|---------|-----------|------------------------------------------------------------|
| id      | bigint PK | Унікальний ідентифікатор регіону                           |
| name    | string    | Назва регіону. Виводиться як title у вимірі region         |


## 5. districts — Райони

Середній рівень географічної ієрархії. Кожен район належить одному регіону.

| Колонка   | Тип       | Опис                                                      |
|-----------|-----------|-----------------------------------------------------------|
| id        | bigint PK | Унікальний ідентифікатор району                           |
| region_id | bigint FK | Посилання на батьківський регіон (regions)                |
| name      | string    | Назва району. Виводиться як title у вимірі district       |


## 6. communities — Територіальні громади

Найнижчий рівень географічної ієрархії. Кожна громада належить одному району.

| Колонка     | Тип       | Опис                                                       |
|-------------|-----------|------------------------------------------------------------|
| id          | bigint PK | Унікальний ідентифікатор громади                           |
| district_id | bigint FK | Посилання на батьківський район (districts)                |
| name        | string    | Назва громади. Виводиться як title у вимірі community      |


## Зв'язки між таблицями

```
damage_notes (факти)
  |
  |-- object_type_id --> object_types --> object_categories
  |                      (тип об'єкта)    (категорія об'єкта)
  |
  +-- community_id --> communities --> districts --> regions
                       (громада)       (район)       (регіон)
```


## Міри куба

| Міра              | SQL                                  | Опис                               |
|-------------------|--------------------------------------|--------------------------------------|
| objects_number    | COUNT(*)                             | Кількість пошкоджених об'єктів      |
| restoration_cost  | SUM(damage_notes.restoration_cost)   | Сумарна вартість відновлення (грн)  |


## Виміри куба

| Вимір            | Таблиця / колонка                    | GROUP BY                              |
|------------------|--------------------------------------|---------------------------------------|
| day              | damage_notes.date                    | DATE(damage_notes.date)               |
| week             | damage_notes.date                    | YEAR(date), WEEKOFYEAR(date)          |
| month            | damage_notes.date                    | DATE_FORMAT(date, '%Y-%m')            |
| object_category  | object_categories.name               | object_categories.id                  |
| object_type      | object_types.name                    | object_types.id                       |
| region           | regions.name                         | regions.id                            |
| district         | districts.name                       | districts.id                          |
| community        | communities.name                     | communities.id                        |
| damage_type      | damage_notes.damage_type             | damage_notes.damage_type              |
